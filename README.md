# 阅读14｜Nanopublication · 参赛作品

把研究材料拆成一条条可独立核查的科研断言，每条绑定原文证据与来源，缺口显式保留。

本仓库是「玻尔 AI 产品挑战赛」**阅读14｜Nanopublication** 赛题的参赛作品（challenge `product-arena-09-0e8befd4`）。
仓库根目录的 [`SKILL.md`](SKILL.md) 就是技能入口，脚本、参考文档与示例全部在本仓库内。

## 目录

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 技能入口：触发条件、调用流程、输入输出、异常处理 |
| `references/` | 方法、数据格式/字段字典、调用说明 |
| `examples/` | 合成示例（非正式案例答案） |
| `scripts/` | 可离线运行的解析/校验/导出脚本 |

## 本版改进

- 断言六槽核验：主体 / 关系 / 客体 / 条件 / 证据强度 / 证据编号，缺槽即判不完整
- `references/assertion_template.json` 提供可填写的槽位模板，减少自由文本糊成一条断言
- 未签名 JSON 映射示例 `docs/mapping_example.json`：断言 ↔ 出处对应关系可直接复用到新材料
- 证据不足项与图表待核位置保留可定位占位，不写成事实
- 严格区分「原文没写」与「没读到」：`not_reported` 只在核对后使用

## 使用

Python 3.10+；只用标准库，PDF 提取可选 `pypdf`。

```bash
python -B -m unittest discover -s tests -v   # 本地回归
```

具体命令、参数与字段说明见 [`references/usage.md`](references/usage.md)。
